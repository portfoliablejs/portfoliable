## Product narrative

Portfoliable is for teams who want portfolio UX quality without rebuilding the same infrastructure every time.
It gives you a reusable runtime, strict content contracts, and a docs-first operating model for contributors.

<div class="feature-grid">

## Why teams choose Portfoliable

- Keep content maintenance lightweight with markdown files instead of manual page builders.
- Reuse one runtime contract across projects generated by the initializer.
- Ship docs and product narrative from a dedicated web workspace.
- Scale with open-source tooling, no proprietary CMS lock-in.

## Build workflow at a glance

1. Scaffold or update case content.
2. Validate markdown contracts.
3. Build and preview locally.
4. Publish packages with release workflow.
5. Publish marketing/docs with web release workflow.
