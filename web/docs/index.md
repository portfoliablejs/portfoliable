## What you will find here

- Installation instructions for local development and CI environments.
- A quick path from scaffold to first successful build.
- Configuration guidance for runtime behavior and theming.
- Content authoring rules for markdown cases.
- Deployment guidance for GitHub Pages release workflows.
- Release-oriented docs for web versioning and changelog discipline.

## Product model

Portfoliable ships as a runtime-oriented package and initializer flow. Your content lives in your own repository, and this docs site is separated from package release automation.

<ds-divider></ds-divider>

## Recommended learning path

1. Install dependencies and run your first local preview.
2. Create or scaffold a case, then validate content contracts.
3. Tune configuration and design tokens for your brand.
4. Publish through CI after smoke and build verification.
