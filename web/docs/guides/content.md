# Content Authoring

Case studies are markdown-first with structured frontmatter.

## Required frontmatter (simplified)

```yaml
id: my-case
slug: my-case
title.en: My Case
title.pt: Meu Caso
shortDesc.en: Short summary
shortDesc.pt: Resumo curto
```

## Authoring workflow

1. Create or scaffold a case.
2. Fill metadata carefully first.
3. Write body content sections in supported languages.
4. Run validation before committing.

## Quality checklist

- Every case has complete localized fields.
- Thumbnail metadata points to valid media assets.
- Links (repo/demo/video) are tested.
- Read-time and year labels are accurate.
