# Accessibility Overview

Portfoliable and Valence are designed to support inclusive interfaces from the component level up.

## Built-in foundations

- Semantic structures in component internals
- Keyboard-focused interaction patterns for controls
- Token-driven color and typography adjustments
- Runtime toggles for common accessibility modes

## Accessibility strategy

1. Treat accessibility as part of the content and component contract.
2. Validate both light and dark surfaces when adjusting tokens.
3. Keep text alternatives present for meaningful media.
4. Test keyboard navigation on every release cycle.

## Where to apply improvements

- Theme tokens in configuration
- Case content readability and heading structure
- Interactive controls in custom page blocks

Accessibility quality should be reviewed with the same rigor as functional correctness.
