## Context
Use this template to document a mobile redesign where usability debt affects task completion.

## Problem Statement
The legacy flow forced users through dense screens, weak hierarchy, and unclear CTA priority.

## Research Inputs
- Session replay and funnel drop-off points.
- Accessibility audit findings.
- Customer support issue categories.

## Design Strategy
1. Reduce cognitive load through stronger information hierarchy.
2. Prioritize one primary action per critical screen.
3. Improve accessibility contrast and touch target sizing.
4. Align copy with user intent for each step.

## Implementation Notes
- Introduced reusable mobile layout tokens.
- Updated navigation transitions for state clarity.
- Added analytics events at decision points.

## Results
- Faster completion for primary task path.
- Improved readability in constrained viewport states.
- Lower abandonment in high-friction steps.

## Retrospective
Main driver of impact was clarity, not additional feature depth.

## Contexto
Use este template para documentar redesign mobile quando divida de usabilidade afeta conclusao de tarefas.

## Problema
O fluxo legado exigia telas densas, hierarquia fraca e prioridade de CTA confusa.

## Entradas de Pesquisa
- Replays de sessao e pontos de abandono.
- Resultado de auditoria de acessibilidade.
- Categorias de chamados de suporte.

## Estrategia de Design
1. Reduzir carga cognitiva com hierarquia mais forte.
2. Priorizar uma acao principal por tela critica.
3. Melhorar contraste e tamanho de area de toque.
4. Alinhar copy com intencao do usuario.

## Notas de Implementacao
- Introducao de tokens reutilizaveis de layout mobile.
- Ajuste de transicoes para clareza de estado.
- Eventos de analytics nos pontos de decisao.

## Resultados
- Menor tempo para concluir caminho principal.
- Melhor legibilidade em viewport restrito.
- Menor abandono nas etapas de maior friccao.

## Retrospectiva
O impacto veio principalmente da clareza, nao do aumento de funcionalidades.
