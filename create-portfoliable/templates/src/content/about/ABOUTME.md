# About Portfoliable

Portfoliable is a markdown-first portfolio builder that helps creators publish clear, fast, and polished case studies.

It keeps the focus on content, not configuration.

## What Portfoliable is

> Portfoliable treats a portfolio like a product: structured, maintainable, and easy to evolve.

It combines `markdown`, design-system components, and practical defaults so a project can stay lightweight without feeling limited.

### What it includes

- case pages with summaries, navigation, and reader controls
- localized content with reusable metadata
- accessibility-friendly defaults for contrast, motion, and reading comfort
- a workflow that stays close to the source files

### Why it matters

1. It reduces setup time.
2. It keeps the story readable.
3. It makes iteration predictable.

| Feature | Value | Example |
| --- | --- | --- |
| Markdown | Easy editing | `# Heading` |
| Lists | Clear structure | ordered and unordered |
| Tables | Compact comparisons | decisions at a glance |
| Footnotes | Extra nuance | explanatory notes[^1] |

## A small example

```md
# About Portfoliable

Portfoliable is a project about making portfolio publishing feel simple.

> It stays out of the way so the work can speak.
```

## Notes

Portfoliable is not trying to be everything. It is trying to be *useful*, **predictable**, and ~~bloated~~ practical.

Term
: A compact way to publish work.

Keep:
- the title short
- the summary focused
- the body easy to scan

Remove:
- anything that does not help the story

Read more at [Portfoliable](https://www.portfoliable.js.org/).

[^1]: Markdown footnotes help add detail without breaking the flow.

# אודות Portfoliable

Portfoliable הוא בונה פורטפוליו מבוסס Markdown שמסייע ליוצרים לפרסם קייסים ברורים, מהירים ומלוטשים.

הוא שומר את הפוקוס על התוכן, לא על הקונפיגורציה.

## מה זה Portfoliable

> Portfoliable מתייחס לפורטפוליו כמו למוצר: מובנה, קל לתחזוקה וקל לשיפור.

הוא משלב `markdown`, רכיבי מערכת עיצוב וברירות מחדל פרקטיות כדי שהפרויקט יישאר קליל בלי להרגיש מוגבל.

### מה הוא כולל

- דפי קייס עם תקצירים, ניווט ובקרי קריאה
- תוכן מקומי עם מטא-דאטה לשימוש חוזר
- ברירות מחדל ידידותיות לנגישות עבור ניגודיות, תנועה ונוחות קריאה
- תהליך עבודה שנשאר קרוב לקובצי המקור

### למה זה חשוב

1. זה מקצר את זמן ההקמה.
2. זה שומר על סיפור קריא.
3. זה הופך את האיטרציה לצפויה.

| תכונה | ערך | דוגמה |
| --- | --- | --- |
| Markdown | עריכה קלה | `# כותרת` |
| רשימות | מבנה ברור | ממוספרות ותבליטים |
| טבלאות | השוואה קצרה | החלטות במבט אחד |
| הערות שוליים | ניואנס נוסף | הערות מסבירות[^1] |

## דוגמה קצרה

```md
# אודות Portfoliable

Portfoliable הוא פרויקט שנועד להפוך פרסום פורטפוליו לפשוט.

> הוא נשאר ברקע כדי שהעבודה תוכל לדבר.
```

## הערות

Portfoliable לא מנסה להיות הכול. הוא מנסה להיות *שימושי*, **צפוי** ו~~מנופח~~ פרקטי.

מונח
: דרך קצרה לפרסם עבודה.

להשאיר:
- כותרת קצרה
- תקציר ממוקד
- גוף שנוח לסריקה

להסיר:
- כל דבר שלא משרת את הסיפור

קראו עוד ב-[Portfoliable](https://www.portfoliable.js.org/).

[^1]: הערות שוליים ב-Markdown עוזרות להוסיף פרטים בלי לשבור את הזרימה.
