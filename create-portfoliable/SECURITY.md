# Security Policy

## Supported versions

Active security support applies to the latest published create-portfoliable release line.

## Reporting a vulnerability

Please report vulnerabilities privately.

1. Open a private security advisory on GitHub for this repository, or
2. Contact the maintainer directly with reproducible details.

Include:

- Affected version
- Impact summary
- Reproduction steps
- Suggested mitigation (if available)

Do not open public issues for undisclosed vulnerabilities.

## Disclosure process

- We will acknowledge receipt as soon as possible.
- We will triage and reproduce the report.
- A fix will be prepared and released.
- Public disclosure follows release of a patch whenever possible.
